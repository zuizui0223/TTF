# TTF-Q fresh CaliPopGen Fst route — response-blind source preflight

- New research branch; excludes prior frozen TTF-Q / original COI / GenDivRange He from analysis.
- Source: [Beninde et al. 2022, CaliPopGen](https://doi.org/10.1038/s41597-022-01479-z), collection 10.6084/m9.figshare.c.5518389.v1.
- Dataset 2 reported: 14,703 pairwise comparisons from 199 studies of 197 species/subspecies, before any filtering.
- A **true Fst** response is required. The source also has other genetic distances; do not mix them.
- Both endpoint coordinates must be usable with CHELSA-TraCE21k and must not be assumed precise if a location has a 25–50 km estimated error.
- Before any Fst values are opened, verify actual file hash, schema, terrestrial eligibility, study-and-locus support, duplicate comparisons, and train/eval species separation.
- Do not rescue the prior GenDivRange He result by selecting favorable markers, subgroups, or transformations.
- Population pairwise Fst is an outcome about magnitude of genetic differentiation, not evidence for the exact *location* of a barrier.
- This branch is a fresh exploratory research protocol; no historical-effect claim is made.
