# Original Penstemon Table S1 visual-layout verification

This single marker triggers a source-SHA-pinned **temporary** render of original Europe PMC Table S1 PDF page 11 and the top of page 12. It follows the result that both pypdf and PyMuPDF extracted 51 complete voucher rows (30 `Phenotyped=yes`), while the publication reports 52 sequenced/34 phenotyped. Only the original layout, not quantitative floral traits, is examined. No original PDF bytes or images are committed to the repository. The run remains non-confirmatory and does not alter frozen TTF or prior P0/P1.
