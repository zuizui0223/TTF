# 未知の研究差・種差を除くと、歴史気候の比較情報がほぼ残らない

2026年11月14日。PR #154。今回完了したのは元の説明変数配置に対する方法・識別可能性の診断であり、実際の植物形質変化率の解析ではない。旧Haldane v1の停止判定は維持する。

## 1. 今回の問いと方法

前回は、種・研究を共有する誤差の共分散が完全に既知という理想条件で関連の検出力を求めた。今回はその条件を弱め、種と研究ごとの平均差をすべて調整変数として取り除いた。種・研究の平均差は任意の未知の値でよく、その分散成分も事前に指定しない。残った誤差の共通分散も未知のまま、Gaussian線形モデルのStudent t理論で扱う。

ただし、残差が独立・等分散・正規分布に従い、共通の歴史係数を持つ線形モデルが正しいことは依然として仮定する。未知の相関をどんな形でも処理できる方法ではない。種ごとの歴史係数の違い、空間依存、系統依存、異分散を解消したとは言えない。

元の評価用74比較・27種・45研究を使用し、現在気候・地理・研究方法の21変数と切片に、種・研究の指示変数を追加した。基準変数の列空間を除いた歴史指標hの残差をrとし、u=r/||r||、全モデルの残差射影をM、残差自由度をdfとする。仮定が成立し歴史係数がゼロなら、(u'y)/sqrt(y'My/df)はt分布に従う。実際のyは読まず、射影と理論的検出力だけを計算した。

## 2. 元の配置で残った歴史情報

| 設計上の数量 | 結果 |
|---|---:|
| 評価比較数 | 74 |
| 評価種数・原研究数 | 27種・45研究 |
| 種・研究の指示変数のランク | 47 |
| 基準変数と種・研究差を合わせたランク | 66 |
| 歴史指標を加えた後の残差自由度 | 7 |
| 基準21変数のみを調整した歴史指標の残差平方和 | 28.6039214796 |
| 種・研究差も取り除いた後の残差平方和 | 0.002381988877 |
| 後者／前者 | 0.00008327490615 = **0.00832749%** |

つまり、この評価配置では、元の基準変数を調整した後に残っていた歴史指標の変動の約99.9917%が、種・研究の指示変数を追加すると除かれる。これは研究・種を跨ぐ差に由来する情報を落とした結果であり、実際の進化的な歴史効果が99.9917%消えたという意味ではない。

この0.0083%の分母は、同じ評価74比較で基準21変数を調整した歴史指標の残差平方和である。以前の70種・11変数の54.20%や56種・21変数の12.85%とは、対象集合、重み、分母が違うので、直接の説明率比較にしない。いずれも植物形質変化率のR²ではない。

残ったコントラストの平方寄与を均等な種数に換算すると5.69種、最大1種の寄与は25.64%。微小な残差は数学的には識別可能だが、科学的に有用な精度を意味しない。

## 3. 正しいモデルを仮定しても検出力は極めて低い

両側有意水準1/60を固定し、仮想的な独立残差の標準偏差を0.5と置いた。これは実測から推定した分散ではなく、比較のために指定した尺度である。

| 仮定する歴史係数γ | 理論的検出力 |
|---|---:|
| 0（帰無） | 1.6667% |
| 0.25 | 1.6688% |
| 0.50 | 1.6754% |
| 1.00 | 1.7014% |

80%の検出力に必要なγは42.0258だった。γの単位は歴史指標が学習群の1標準偏差変化した際の仮想応答単位であり、Haldanesや適応度の実測値ではない。先の既知共分散モデルとの違いは、単に分散を未知にしただけではなく、種・研究間の歴史情報も取り除いたことによる。

現デザインに任意の種・研究平均差を許し、指定された基準変数も保ったままでは、研究・種内の歴史的関連を有用な検出力で識別する比較がほぼない。この診断からは、元の条件を緩めるのではなく、新しい研究設計で同一研究・同一種内の歴史気候差を確保する必要性が示唆される。より強いモデル仮定を置いて種・研究間情報を利用する方法まで否定するものではない。

## 4. 今回の数値不一致は演算経路の切替で再現・解消

最初の実行43604455628は、歴史指標H、原本CSV、座標、気候8変数が一致した一方、21変数のXだけが不一致だったため停止した。その記録は保存した。

次の実行43605074403では、同じAMD EPYC 9V74のホスト、同じデータ・コードのまま、通常実行、別プロセスの通常実行、AVX512経路無効、全dispatch無効の4設定を比較した。通常の2設定は先の不一致Xを再現した。AVX512を使う経路を無効にした設定とbaseline設定では、XとHの両方が元の凍結SHA256に完全一致した。

異なっていたXは46要素、0始まりの列番号9・10・13・14で、最大の数値差は3.637978807091713e-12。これらは地点中点の経度、距離、世代数中央値のlog1p、元記録数のlog1pに対応する。Hの異なる要素はゼロ。原本処理コード10ファイルの内容も元の計算時と一致した。今回の不一致については、同一ホストでの数値関数の演算経路の変更が差を生むことを確認できた。

完全一致した元のX/Hだけを方法診断に使用した。丸め、ハッシュ置換、許容誤差による通過は行っていない。観測ハッシュ・CPU情報が保存されていない過去の別の失敗まで、同じ原因だったとは断定しない。
