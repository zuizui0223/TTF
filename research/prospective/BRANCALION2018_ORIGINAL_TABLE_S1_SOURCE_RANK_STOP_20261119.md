## 2. 原著Methodsだけで証明できる独立単位の上限

原著Methods §2.1・2.4–2.7に明記された原産集団3、各10母樹（計30）、3調査地に各8ブロック、各ブロックに3プロット、種子／苗移植、共通圃場の数量だけを使用。`brancalion2018_source_level_design_ceiling_v01.py`が元の10研究source-only shortlistと原著の設計数を照合する。

| 水準 | 原著Methodsからの値 | 独立した歴史気候曝露数か |
|---|---:|---|
| 原産集団（森林3タイプ各1サイト） | **3** | **最大3**（元GPS認証は0） |
| 由来する母樹 | 30 | いいえ（3原産集団に入れ子） |
| 移植先サイト | 3 | いいえ（原産地気候の追加反復ではない） |
| 移植ブロック | 24 | いいえ |
| プロット（8×3×3） | 72 | いいえ |
| 種子移植の配置個数（計画値） | 2,160 | いいえ |
| 苗移植の配置個数（計画値） | 2,160 | いいえ |
| 共通圃場の苗配置（計画値） | 60 | いいえ |

**これらはMethodsから導いた設計上の配置数であり、実際の測定成功数・独立個体数・生存数ではない。** 種子ロットは3種類の実験を通じて同一30母樹に由来し、森林環境タイプは各1地点のみ。したがって森林タイプと固有サイト効果をこの1研究だけで独立に識別することもできない。

単一研究内の原産地気候説明行列は高々3行（3曝露地点）。**切片＋現代気候2変数＋LGM1変数＝少なくとも4列**のモデルなら、どの座標が判明しても必ず階数不足。切片＋現代気候1＋LGM1＝3列ですら残差自由度は最大0（完全階数の場合）。旧Bontrager型の多数調整共変量の独立LGM効果は、単独研究内では推定・不確実性検証できない。

この結論はBrancalionの原著が報告した局所適応の結果を否定しない。複数の独立原著・原産集団をpoolする新しい階層パネルを原理上禁じるものでもない。ただしこれを1つの独立したLGM×適応の確認的論文として扱ってはならない。

## 3. 判断と次の現実的な作業

**Brancalion = ORIGINAL_TABLE_S1_BYTES_NOT_RECOVERED + SOURCE_EXPOSURE_N=3 + NO_NEW_LGM_PANEL**。

単なる元座標の回収より、ほかの原著研究について**独立した原産集団・真正GPS・別コホート**を横断的に増やすことがボトルネック。Brancalionが提供できるのは同一母樹由来の実験条件差・局所適応の既刊証拠であり、現在気候・地理・歴史気候の独立寄与を単独で評価する多数の独立曝露ではない。
