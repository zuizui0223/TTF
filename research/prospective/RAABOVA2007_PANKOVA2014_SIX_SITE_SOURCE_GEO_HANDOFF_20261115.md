# 重要追記 — 2007年と2014年は同じ2004年成体移植コホートの追跡である可能性が高い

**位置照合の計算値は変更しないが、2014年を2007年とは独立の移植実験とは扱わない。** 原著Methodsを照合すると、両方で**2003年採種→2004年2月約300粒/原産集団を10°C温室播種→4月3×3cmポット→10月野外移植→同一6集団・6サイト、原産集団25個体/サイト、5列、10cm間隔**と一致する。2007年は2005–2006年の成体移植の追跡を報告し、2014年は2009年までの5年追跡を報告した。したがって**同じ2004年の成体移植個体群を長期追跡した可能性が非常に高い**。ただし、生個体ID・標識との1:1照合は未実施なので同一個体集合の完全証明ではない。2007年の2003/2004の種子播種実験を2014年実験と同一とは扱わない。

科学的含意：Pánková 2014 Table 1の全6集団同名・同コードの座標は貴重な出典だが、**2007年から独立した実験標本でも、独立したGPS測定でもない可能性が高い**。本件の距離0.7–1.9kmは場所の記録差であり、採集地と移植プロットやジオコーディング座標が何を表すかを区別できない。[原著Methodsコホート照合JSON](./raabova2007_pankova2014_probable_shared_adult_cohort_v01.json)に根拠と未確定要素を固定した。以下の「別の相互移植実験」という旧記述は本追記により**訂正**する。

### 2. 公表地名座標どうしの一致

同じ共同研究系の[Castro et al. 2011, Evolutionary Ecology Table 1](https://doi.org/10.1007/s10682-010-9439-5)にも、S1=Malíč、S2=Holý vrch、S3=Encovanyの**2倍体**の同じ地名がDMS小数秒の位置情報とともに載っている。DMSをWGS84座標へ変換し、既存のHaversineで2014との距離を計算すると：

| 北ボヘミアの集団 | Castro 2011とPánková 2014の位置差 |
|---|---:|
| S1 | **約6.5 m** |
| S2 | **約5.0 m** |
| S3 | **約8.5 m** |

これらは**2本の後続文献で印刷されたサイト座標の一致**であり、同じ研究者の原位置情報を再利用している可能性がある。独立した野外GPS測定・座標精度の証明ではない。

同じS1–S3について、**Hargreavesの移植先由来代理座標との差は0.7–1.9km**あった。原論文のサイト中心、実際の移植プロット、メタ解析用に地理参照した地点が一致するとは限らない。現在の証拠だけでは何を原因としてずれたか特定できず、いずれかの数値を「誤り」と断定しない。
