# TTF — 現在の寄主気候ニッチの参照点数とLGM回廊コスト（2026-10-17）

**分類：遺伝的応答開封後の、外部気候・採集地理データだけを用いた探索的感度分析。確認的な生態学的・遺伝的検定ではない。**

## 問題

従来の原本CHELSA回廊パイロットでは *Bungalotis erythus* の26採集地点・64元の辺に対し、寄主植物の現代気候ニッチは665点、昆虫自身の現代気候ニッチは26点を基準とする。この参照点数の非対称性によって、LGMから現在への最小コスト経路の変化が不公平に見えていないか。

## 方法の固定と入力

- 2026-10-17、**新しい希釈結果の参照前**に `docs/supporting/host_memory_bungalotis_26point_rarefaction_contract_v0.1.json` を凍結（コミット `1ea7f7bc13e43304f8e1f4ef7039328c6326f2eb`、SHA256 `8f9ce1fa83a5a0ead8ab68a7278bd6b6e4d6695241fd515bdfd31bc062da3c72`）。この分析は旧結果を見た後の探索であり、**新規事前登録ではない**。
- 元のCHELSA-TraCE21k v1.0 `bio01, bio07, bio12, bio15`、LGM `-190`・現在 `20` の8ラスタ、および元のHOSTS/WCVP・WGSRPD3を再利用。すべての原本SHA256を照合。
- 元の101×57セル・5,757有限セル、ROI余白0.12°、26地点・64辺（うち同一ラスタセル1辺）、4近傍の正のコストに対する測地距離加重Dijkstraを**一切変更しない**。
- 元の寄主665点と昆虫自身26点の4種の回廊コストを全64辺で再計算し、原本の保存済み64辺CSVと最大絶対誤差**0.0**で一致することを確認してから、希釈を開始。
- 665点の寄主現代気候参照から**26点を無復元抽出**することを、事前固定のPCG64乱数で独立に**64回**繰り返す。植物種ごとの重み変更・新たな寄主除外なし。昆虫自身の26点参照は固定。
- 各抽出で現在・LGMの元64辺の回廊を再計算し、平均の `LGM − 現在` および `寄主差分 − 昆虫自身差分` を保存。報告する5%・95%分位は**64回の参照点抽出に関する記述的変動幅**であり、信頼区間や独立な生物学的複製ではない。

## 確認された結果

| 比較モデル | 元の回廊差（LGM−現在、平均コストkm） |
|---|---:|
| 寄主現代気候ニッチ **665点** | **+1.6658** |
| 寄主現代気候ニッチ **26点、64回抽出の平均** | **+5.6885** |
| 昆虫自身の現代気候ニッチ **26点、固定** | **+17.7942** |

寄主の参照点を揃えると、寄主のLGM−現在差は平均 **+4.0227コストkm増加**し、元の3.4倍になった。寄主差分と昆虫自己差分の差は、元の **−16.1284** から希釈後平均 **−12.1057** へ変化した。元の符号付きの差の絶対値は約**24.94%縮小**したが、これはコスト差の算術比較であり、生態学的な原因寄与率ではない。

希釈した寄主の回廊差は、64回の**中央値+4.6734**、5%分位**+0.3631**、95%分位**+13.1079**、範囲 **−0.1499～+14.1028**。63/64回で正、1/64回で負。寄主差分－自己差分は**64/64回で負**、範囲 −17.9441～−3.6914。これらから統計的なp値は計算しない。

## 解釈の境界

**この1種のモデル内では参照点数の違いが比較に影響するが、それだけでは2つのニッチの差を消せなかった。** ただし、寄主の665点は3植物の現代WGSRPD3 native unit climate unionであり、昆虫の26点は標本採集地点の気候である。両方26点にしたからといって、真の生態的なニッチ幅・空間範囲・観察努力・分散制約が揃うわけではない。

コストkmは気候適合性の最小経路コストであり、分散距離、氷期に実在した寄主の地理分布、古地理の障壁や遺伝子流動ではない。NOAA ETOPOの元ROIでは現代に22,914/22,914セルが陸上だが、その地形マスクは**今回のCHELSA気候コスト計算には組み込んでいない**。氷床・古地理・当時の植物実在は不明。

対象昆虫のCOI応答は過去に開封済みだが、今回の計算に配列や遺伝距離を一切入力しなかった。元の259種の確認的な `NOT_EVALUABLE_EMPIRICAL_RESPONSE` と未定義p値は変更しない。この探索結果を使って元の259種の寄主履歴検定を救済してはいけない。
