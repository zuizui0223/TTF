# TTF：CHELSA実データの二次元・寄主気候回廊パイロット（2026-10-13）

**区分：LGM／現在の気候上の潜在的な回廊に関する探索的パイロット。これは植物の氷期分布復元でも、COI遺伝構造の再検定でもない。**

## データ・解析条件

実行：[GitHub Actions #38363106557](https://github.com/zuizui0223/TTF/actions/runs/38363106557)（成功）。既存の出典・科学的ルールを変更せず、**2026-10-13に結果を初めて見る前に固定した** `docs/supporting/historical_host_climate_lcp_pilot_contract_v0.1.json` に従った。凍結したCHELSA–TraCE21k v1.0の`bio01, bio07, bio12, bio15`、時点 `-190` (LGM)・`20` (0 BP)、WCVP/HOSTS寄主記録、WGSRPD3の現代分布を使用。

対象は *Bungalotis erythus*（以前のCOI応答は既に開封済みの種）の**26地点・元の64辺**。これは新しい独立遺伝検証ではない。原本グラフと元の気候変数から、緯度経度0.0083333333°の格子を**101行×57列**に切り出した。固定の地理的ROI余白は各辺0.12°、全5,757セルについて8層の気候値が有効であったが、**有効な気候セルが陸上、氷床外、昆虫の通過可能範囲である保証はない**。

寄主側の気候ニッチ基準は現代WGSRPD3の665点・3種の植物のユニオン、昆虫自身は現代の26採集地点を基準とする。気候ベクトル4変数は共通の現在気候参照に従い標準化し、セル気候コストを `1 + 最寄り気候アナログまでのユークリッド距離` と定義した。隣接4セルを許すDijkstraで、各グリッド遷移について「隣接2セルの平均抵抗×セル中心の測地距離(km)」を合計した。単位は**気候コストkm**、移動距離・実際の通過頻度ではない。元の64辺のうち1辺は両端が同じラスタセルに入り、経路コスト0になった（格子離散化上のアーチファクトとして記録）。

凍結した直線上5地点の旧予測因子（`M_host`, `M_self`, `D_host_0BP`, `D_host_LGM`, `D_self_0BP`, `D_self_LGM`）は、**全6列・64辺で最大絶対誤差0**となり、CHELSA・寄主気候データとの原典整合が確認できた。

|---|---:|---:|---:|
| 記録寄主植物の現代気候ニッチ | 10.3863 | 12.0521 | **+1.6658** |
| 昆虫自身の現代気候ニッチ | 9.5506 | 27.3448 | **+17.7942** |
| 寄主差分 − 自己差分 | — | — | **−16.1284** |

寄主差分は63/64辺で正、1辺（同じラスタセル）で0。昆虫自身の差分も63/64で正。寄主差分−自己差分は**63/64で負、1/64で0**。これは「昆虫自身の現代ニッチから見たLGMの気候コスト上昇のほうが大きい」という**気候モデルの内部結果**にとどまる。

独立した64辺CSVの再集計では、変化量と元の地点間弦距離のPearson相関が寄主**+0.9130**、昆虫自己**+0.9523**だった。距離で割った平均（各辺の差分を各辺の元の直線距離kmで割り、64辺を単純平均）は寄主**+0.2343**、自己**+2.6802**（次元のない気候コスト密度の変化）であった。強い距離依存があるので、単純な回廊コスト差を採集配置と無関係な歴史的障壁の強度として解釈することはできない。64辺は26地点を共有しており独立な統計標本ではない。新しいp値や信頼区間は計算していない。

## もっとも重要な解釈上の制約

1. **寄主気候参照665点と昆虫自身の気候参照26点が非対称。** 広い現代寄主気候ニッチと狭い昆虫採集地点ニッチでは、全地図で最寄りアナログコストの大きさが違って当然である。差分の大小をそのまま「昆虫のほうが本当に分断された」とみなすことはできない。これを科学的結論ではなく、今後の設計で事前対処すべき比較可能性の問題として記録する。
2. **古地理の陸地・氷床マスクを未適用。** コスタリカの対象範囲に気候の連続格子があっても、現在・LGMの実在陸地および植物・昆虫にとって通行可能な経路と同じとは限らない。
3. **ROIの範囲は26採集点の外接矩形＋0.12°に固定。** 迂回に有利な経路がこの外にあればDijkstraは使えない。コストは切り出した範囲に条件付けられている。結論を見て適応的に広げて検定をやり直すことはしない。
4. **現代の寄主記録による4変数気候アナログはLGMの宿主実在分布ではない。** 過去の寄主利用、遺伝子流動、地理的障壁や因果効果はこのモデルから証明できない。
5. 元の259種の確認的遺伝検定は**`NOT_EVALUABLE_EMPIRICAL_RESPONSE`**のまま確定している。この実行では配列塩基同一性、遺伝距離、COI応答、遺伝効果量を読んでいない。
