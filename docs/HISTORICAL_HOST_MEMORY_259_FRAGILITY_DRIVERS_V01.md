# TTF：寄主履歴係数の地点依存性を説明する条件（2026-10-12）

**区分：遺伝データ開封後の探索的監査。確認的な新規検定ではない。**

凍結済み259種・20,362本の辺について、元の確認的解析は `NOT_EVALUABLE_EMPIRICAL_RESPONSE` である。4種でCOIの補正後応答に変動がなく、当初の標準化応答を定義できなかった。元のp値は未定義のままであり、今回の分析でも新たなp値、帰無分布、種の再選択は作っていない。開発用320種の遺伝的応答も開いていない。

## 分析の対象

前回、一度だけ地点を除く感度解析をした6,374通りの記録を再利用した。6,373通りで傾きが定義でき、1通りは地理的な訓練辺不足で未定義だった。259種にはゼロ変異4種を残すが、**符号反転の定義自体には標準化係数が存在する255種だけ**を使用する。これは確認的解析から4種を除外する操作ではない。

確認された反転は255種中129種、地点除外では420/6,308通り（6.66%）。「一度でも反転する種」と「任意の地点を1つ削って反転する割合」は別である。原本の塩基配列や辺ごとの遺伝距離は開かず、過去に保存された所有者専用の派生係数・地点除外記録だけを扱った。

## 係数の絶対値による4群

| 標準化係数の絶対値 | 種数 | 1度以上の符号反転 |
|---|---:|---:|
| 最小25% | 64 | 57（89.1%） |
| 次の25% | 64 | 40（62.5%） |
| 次の25% | 63 | 19（30.2%） |
| 最大25% | 64 | 13（20.3%） |

元の係数が小さいほど符号を変えやすい。ただし、一部の絶対値の大きな係数も特定地点に強く依存する。

## 寄主履歴の半偏相関の絶対値による4群

独自の寄主履歴成分の割合を `u`、標準化した寄主履歴の回帰係数を `beta` とする。原本で応答の標準化が定義できる種に限り、半偏相関との**数学的恒等式**は

`r_semi = beta * sqrt(u)`

となる。原本255種すべてで、保存済み半偏相関との最大差は5e-16以下だった。

| 半偏相関の絶対値 | 種数 | 1度以上の符号反転 |
|---|---:|---:|
| 最小25% | 64 | 56（87.5%） |
| 次の25% | 64 | 44（68.8%） |
| 次の25% | 63 | 21（33.3%） |
| 最大25% | 64 | **8（12.5%）** |

半偏相関によって「大きな標準化係数だが寄主履歴がほかの環境指標と重複している」事例を、ある程度区別できる。しかし、両者は同じCOI応答から計算した量であり、**半偏相関の高さは送粉や寄主利用の因果関係を独立に示すものではない**。

## 科を丸ごと検証側に回した内部予測

同じ種の感度を説明する記述的予測について、5分割 `GroupKFold` （family単位）、種を1行、`StandardScaler`を訓練側だけに当て、固定した `LogisticRegression(C=1)` で比較した。ハイパーパラメータ探索はしていない。

| 使用したデータ | Brier誤差 | AUC |
|---|---:|---:|
| 係数の絶対値＋元の地点数 | 0.1401 | 0.8777 |
| 半偏相関の絶対値＋元の地点数 | **0.1210** | **0.9064** |
| 半偏相関＋地点数＋記録された寄主種数 | 0.1228 | 0.9025 |

半偏相関を使うとBrier誤差は13.7%低下した。だが、これは「遺伝的応答から得た係数で、同じ応答の地点除外感度を予測している」という**内部的な説明**であり、独立なCOIデータへの外的検証ではない。生態学的な寄主記憶のモデル検定結果でもない。

## 寄主植物という外部制約

凍結済みHOSTS/WCVP情報から記録されていた寄主植物種数は1～3の範囲である。259種内の内訳は、寄主1種143昆虫種、寄主2種70昆虫種、寄主3種46昆虫種。記録された寄主種数を追加しても、内部予測の改善は見られなかった。ただしこれは**寄主範囲の全記録ではなく、以前固定した部分集合**である。1種しか記録されていないことを実際の単食性と同一視してはならない。

今回の探索記録は、元の環境ニッチと寄主気候の独自性、地理的サンプリング、そしてCOIの遺伝的変動幅を峻別するためのもの。寄主植物が氷期に実際にその地点にいたことも、現在のCOI系統構造の因果原因も、この解析からは確定しない。
